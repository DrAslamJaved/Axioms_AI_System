# Content Creation Agent

## Purpose

The Content Creation Agent creates reviewable blueprints for educational videos, course
modules, and workshops. It structures titles, descriptions, scripts, chapters, thumbnail
briefs, and accessibility checks while keeping educational accuracy ahead of engagement.

## Inputs and outputs

- Inputs: topic, format, audience, duration, approved source scope, learning outcomes,
  application context, optional keywords, and language mode.
- Outputs: title options, description framework, timed content plan, thumbnail brief,
  accessibility checks, accuracy checks, and DOCX export.

## Guardrails

- The blueprint is not a verified script. The author must verify every mathematical,
  scientific, historical, and application claim against approved sources.
- Keywords are metadata prompts, not evidence of search rank or predicted engagement.
- No clickbait, misleading credential, outcome, performance, or certification claim is allowed.
- Bilingual output includes review markers; technical translation requires subject-matter review.
- Captions/transcripts, alt text, readable visuals, and explanation of equations/diagrams are
  required before publication.
- The agent cannot publish, upload, schedule, or share content. Human approval is mandatory.
